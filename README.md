# 苗木配置与生长预览系统

面向园林设计院方案汇报的浏览器端三维苗木配置工具。TypeScript + three.js 实现，纯前端、零后端，方案数据存浏览器本地。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://127.0.0.1:5180
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

## 五个页面

| 页面 | 功能 |
| --- | --- |
| 苗木库 | 15 种内置园林苗木参数卡、程序化缩略图、自定义树种编辑器 |
| 场地编辑 | 道路/水面/草坪/铺装多边形绘制、单株种植、片植刷、拖放种植、间距实时检查、禁种区 |
| 三维预览 | 四季切换、日期时刻太阳轨迹、风力、三档画质、实时阴影、性能 HUD |
| 生长模拟 | 0–30 年按年播放、渐近指数生长模型、冠幅挤压冲突列表与定位 |
| 汇报导出 | 视角截图、苗木清单、CSV 导出、打印/PDF 汇报书 |

## 核心设计

### 确定性（同种子同树）
- 全程使用自带的 mulberry32 种子随机数（`src/core/rng.ts`），树木生成不调用 `Math.random`。
- 树种几何由 `hashString('treegen-v1:' + speciesId)` 派生规范种子，配合变体序号生成；同树种同变体在任何环境逐顶点一致。
- 场地每棵树的种子由坐标与种植序号派生，可复现。启动时 `main.ts` 会跑确定性自检。

### 程序化树木（`src/tree/generator.ts`）
- 递归分枝骨架：阔叶类主干分段 + 侧枝递归，针叶树轮生枝，垂柳末梢下垂。
- 叶团用 icosahedron 沿枝梢分布，包络收敛到树种冠幅；带 `aRand`/`aFlower` 顶点属性供着色器做落叶与开花。
- 每树种 3 个共享几何变体，单位化（成熟树高=1）后实例按生长比例缩放，实例再做旋转与 ±8% 冠幅抖动。

### 性能（目标 1000 树中档 60 帧）
- **三级 LOD**：近景高模 → 中景低模 → 远景圆柱公告板（离屏渲染的图集纹理）。
- 全部走 `InstancedMesh`，按 `树种 × 变体 × LOD × 部件` 分桶，远景 1000 树仅个位数 draw call。
- LOD 带距离滞回带 + 相机移动阈值触发 + 级别变化检测，避免相机抖动导致的频繁重分级。
- 风摆、季节变色、落叶 discard、开花混合全部在 GPU 着色器完成，切换季节/年份不重建几何。

### 季节与生长
- 年相 `t∈[0,1)` 关键帧插值：落叶树叶量、叶色（春绿/夏深绿/秋色/冬秃枝）、花期；常绿树冬季不落叶。
- 生长用渐近指数模型 `s(age)=s₀+(1-s₀)(1-e^(-k·age))`，纯函数，同年份结果恒定。
- 间距检查空间哈希分桶 O(n)，支持「当前冠幅 / 成年冠幅」两种口径。

### 持久化
- 自动保存 + 命名存档槽 + JSON 导入导出，均基于 localStorage / 文件，无后端依赖。

## 目录结构

```
src/
  core/      类型、树种库、RNG、季节、生长模型、状态仓库、本地存储
  tree/      程序化生成器、风/季节材质、模型库与公告板、实例树场
  scene/     渲染器、相机、太阳天空、地面分区、动画循环
  pages/     五个页面 + 共享 3D 视图装配
  ui/        DOM 助手、路由外壳、全局样式
```

## 已知边界
- 公告板纹理按夏季叶色烘焙，远景树不随季节变色（近景网格树完整响应季节）。
- 浏览器软件渲染（SwiftShader）下帧率显著低于独立 GPU，属环境限制；真机 GPU 下 1000 树中档可稳定 60 帧。
